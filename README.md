# North Star Technologies website

A static site: plain HTML, CSS and a little JavaScript, generated by one dependency-free Node script.
GitHub Actions builds and deploys it to GitHub Pages on every push to `main`.

## Change something

| To change | Edit |
| --- | --- |
| The company name, mission, vision, systems principle, phone, email, address | `site.config.json` (the only place the name is written) |
| Capability layers | `content/layers.json` |
| Services | `content/services.json` |
| Metrics and milestones in Progress and status | `content/status.json` (set `updated` to today's date) |
| Water devices and their stage | `content/water.json` |
| Career ladder | `content/ladder.json` |
| Colours, type, layout | `src/styles.css` (tokens are at the top) |
| Page structure | `build.mjs` |

`{{name}}`, `{{shortName}}` and `{{service}}` work inside any content file and are filled from `site.config.json`.

## Add a field note

Add a Markdown file to `content/field-notes/`, named `004-short-title.md`:

```md
---
number: 4
title: The title of the note
date: 2026-12-01
summary: One or two sentences shown on the card.
tags: Plumbing, Measurement
---

## The problem

Text, lists, numbered steps and tables all work.
```

The home page shows the three newest notes. Every note gets its own page.
`sample: true` in the header adds the "Example note" banner. Leave it out for a real note.

## Publish a real number

In `content/status.json` a metric with `"placeholder": true` is drawn with a dashed border and a Placeholder tag.
Put the real figure in `value`, add a `source`, and delete the `placeholder` line.

## Preview on your own machine

```bash
npm run preview
```

Then open http://127.0.0.1:4717. Needs Node 18 or newer and Python 3.

## Deploy

Push to `main`. The workflow in `.github/workflows/pages.yml` runs `node build.mjs` and publishes `dist/`.
In the repository's Settings → Pages, the source must be **GitHub Actions**.

All links are relative, so the site works at `username.github.io/repo/` and at a custom domain without changes.
For a custom domain, add it in Settings → Pages.
